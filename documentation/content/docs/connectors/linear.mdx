---
title: Linear
description: Query and update Linear issues from a dock through the GraphQL API or MCP.
---

Connect with a personal API key (`PUT /v1/workspaces/:workspaceId/connectors/linear`
with `{ "token": "lin_api_..." }`) or with OAuth when `LINEAR_CLIENT_ID` and
`LINEAR_CLIENT_SECRET` are set. See [Connectors](/docs/connectors) for the routes.

| | |
|---|---|
| OAuth scopes requested | `read`, `write` |
| GraphQL in a dock | `$DOCK_LINEAR_API_URL/graphql` (the only API path) |
| MCP in a dock | `$DOCK_LINEAR_MCP_URL`, listed in `~/.config/dock/mcp.json` |

OAuth access tokens last 24 hours and are refreshed by the control plane.

An issue assigned to the connected user, or labelled `dock`, by a non-guest member
of the organization starts a run and is answered with a comment and state changes;
see [Triggers and replies](/docs/connectors/triggers).

```bash
curl -H "Authorization: Bearer $DOCK_CONNECTOR_TOKEN" -H "content-type: application/json" \
  -d '{"query":"{ viewer { name } }"}' $DOCK_LINEAR_API_URL/graphql
```
