Dock gives agents isolated Linux machines. Each one is a Dock: a persistent
machine with a stable ID that you can stop, resume, snapshot, and branch into
independent copies. Dock is open source (AGPL-3.0). Self-hosting is free and
runs on your laptop or your servers ([Self-hosting](/self-hosting)). Dock Cloud
is coming soon.

Dock does not install or version coding agents. Bring any agent and install it
in your environment setup script.

## What you can use today

- The [`dock` CLI](/cli), installed as a signed release binary, and client SDKs
  for [TypeScript, Python, and Go](/sdks), installed from GitHub until they are
  published to package registries. Both are early.
- REST API at `<your origin>/v1`, with a `{ ok, data }` envelope and `dock_`
  API keys as bearer tokens.
- Docks: create, list, get, update, stop, resume, branch, and delete, with a
  size you choose (`cpus`, `memoryMiB`, `diskGiB`).
- Running commands inside a Dock with `POST /v1/docks/:id/exec`.
- SSH through the control plane's gateway, and hosted ports at a public URL on
  instances with a ports domain configured.
- Snapshots, environments (variables, secret files, repository links), and
  webhooks.
- The GitHub connector: credentials stay outside the dock.

Start with the [Quickstart](/quickstart) and the [concepts](/concepts/docks).

## Not built yet

A local engine that runs Docks on your machine without a control plane is
planned. The CLI and SDKs talk to a control plane today. `dock cp` is missing
because the API has no file endpoint for live Docks.
